# Measurements

The initial scratch campaign completed576 fresh processes on each required Linux
host before repository changes. Every returned record, final live state and
representation invariant passed the independent tree oracle. Initial results
remain external and separate from the exact committed-source campaign.

Exact-source results and receipts are added after the committed run. See
BENCHMARK.md for predeclared workloads, timing boundaries, paired selection,
A/A diagnostics, fixed stopping and measured-versus-inferred limits.
